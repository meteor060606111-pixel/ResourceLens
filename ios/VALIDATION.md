## 真机内存

使用 Xcode Instruments Activity Monitor，按目标 App 进程的 `memory-physical-footprint` 统计。没有向 App 添加采样代码，也没有使用调试构建。

| 场景 | 采样结果 |
| --- | --- |
| 重新启动，已有两份文件，列表静置约 30 秒 | 22.25–26.00 MiB，中位数 25.77 MiB |
| 先前视频预览后，新建下载输入及识别 | 51.80–54.06 MiB |
| 本地 MP4 视频预览 | 本次峰值 65.16 MiB |
| 关闭视频预览，回到列表 | 回落至约 57.55 MiB |

后两项来自同一段约 95 秒记录。测试视频约 1.13 MB；这些数据描述本次短时流程，不能当作任意高清视频、HLS 或长期使用的内存上限，系统独立后台传输进程也不计入 App 进程数值。

## 安装与能力范围

当前手机上的 App 为开发签名，本次配置文件有效至 2026-10-23。安装完成后日常下载和播放无需连接电脑；签名到期后需重新签名。公开发布附件是未签名预览，不能直接点击安装，也不是 App Store 或 TestFlight 发行。

支持 HTTPS 视频、图片与文件直链，以及静态网页公开的直接媒体地址。首版没有桌面的 B 站、抖音等专用解析器，不能承诺任意平台分享链接可用。HLS 使用系统离线包，真机 HLS 后台、长时间锁屏、网络切换和大量任务仍待单独验收。
