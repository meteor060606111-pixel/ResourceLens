# 版本记录

## 1.2.1

修复抖音根级 DASH 标记错误覆盖具体 MP4 档位、导致最高可用带声音媒体被跳过的问题。已验证的播放来源在本机内存中保留五分钟，下载时先检查并复用有效来源，失效后再解析；避免每次点击下载都启动新的匿名浏览器请求。保留具体失败原因，安装包后续单独生成。

## 1.2.0

增加统一暂停续传及持久化任务、逐资源画质选择、封面和媒体预览、关联资源分组、后台批量解析、重复提醒、分类命名与缓存管理。补充首次引导、单实例激活、环境自检、脱敏诊断、本地升级及可配置的在线更新源；新增快手、小红书公开媒体解析。

修复长临时目录导致视频引擎输出路径被截断、取消旧失败任务误清理新任务共用缓存，以及安装失败后恢复结果提示不准确的问题。安装包在后续单独生成。

## 1.1.8

视频号捕获页面跨应用重启自动重连，显示旧页面未加载捕获脚本的状态；提供双击安装及桌面快捷方式。

## 1.1.7

分开保存平台标注大小和实际播放流大小；探测可用画质，显示实际文件大小与分辨率；获取不到严格要求的版本时停止下载。
