拾流 1.7.2 升级下载队列与 macOS 更新体验，并显著缩小应用体积。

- 音乐和视频引擎共用一套 Node.js，移除 Node 开发工具、Python 开发组件与调试符号；保留音乐平台依赖、运行数据和许可证。Apple 芯片本机安装包从约 343.5 MiB 降至 225.7 MiB，缩小约 34%。
- 下载任务可设优先、普通、空闲时三档优先级和预约时间。进行中的任务继续传输，预约任务到时才申请下载名额；暂停队列只停止发起后续任务。
- 设置中可选每任务限速，HTTP 分段共享限额，视频任务限速时使用单片段下载。取消或暂停可立即中断限速等待。任务优先级和预约时间随下载记录保留，重启后按暂停任务恢复。
- Mac 默认从本项目 GitHub Releases 检查本机芯片对应的稳定版，无需填写自定义更新清单。可关闭自动检查；安装需本人点击确认。
- 应用内更新核对 SHA-256、应用标识、芯片、版本与签名完整性。在同一文件系统交换应用目录，校验失败恢复原应用；成功后清理旧程序与暂存安装包并自动打开。配置和已下载文件保留。
- 构建输出使用 .noindex；成功打包后清除暂存 .app、DMG staging 和旧安装包，减少 Launchpad 中出现重复应用。
- 保留 macOS 原生标题栏拖动与现有玻璃界面；浏览器扩展本轮不做。新增开源项目手机连接方式的源码调研文档。

macOS 14+；Apple 芯片与 Intel 安装包分别发布。完整视频和音乐引擎继续内置。当前安装包使用 ad-hoc 签名，尚未使用 Developer ID 或 Apple 公证；签名完整性校验和 GitHub SHA-256 不等同 Apple 公证。本轮未嵌入 Sparkle，也未添加无人值守安装。
