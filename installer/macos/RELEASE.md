新增动态玻璃效果：缓慢流动的背景、跟随鼠标的控件高光（按钮本体不发生位移）、面板过渡和下载进度光带。macOS 窗口使用系统背景模糊；「设置 → 界面外观」支持透明程度、减少透明效果和减少动态效果，并尊重系统偏好。

拾流 1.6.0 重整桌面工作台：半透明玻璃导航、浮动工作区、紧凑捕获提示和独立资源详情栏。资源列表显示清晰表头，支持按时间、名称或大小排序、多关键词搜索及类型计数。

下载任务采用统一列表，集中显示真实进度、速度、状态以及暂停、续传、重试、预览和 Finder 定位。任务搜索可以与状态筛选组合。设置改为六个类别，固定保存按钮并保留跨类别、跨页面的未保存草稿。修复快速切换导航时出现错误页面的问题；新增添加、搜索、切换页面及关闭详情的键盘快捷键。

支持 macOS 13.5 及以上，内置 FFmpeg、FFprobe、yt-dlp 与 Node.js，提供 Apple 芯片和 Intel 两种 DMG。打开安装包，将 ResourceLens.app 拖入 Applications；更新保留本机配置、记录及下载文件。安装包的 SHA-256 见同名校验文件。

当前使用 ad hoc 本地签名，尚未取得 Apple Developer ID 签名及 Apple 公证。首次启动若提示无法验证开发者，按 DMG 内说明通过右键「打开」或系统设置的「仍要打开」完成确认。真实 Mac 微信视频号捕获仍需要本机验证。首次捕获的系统代理、钥匙串授权和使用限制见仓库中的 macOS 说明。
