拾流 1.6.4 将已发布 Windows 1.6.3 的音乐功能完整适配到 Mac，并修复窗口拖动问题。透明标题栏由 macOS 原生管理，网页避开标题栏，不再手动计算或修改拖动坐标。资源列表恢复四角圆角，移除底部重复分隔线，较矮窗口中的空状态内容可正常显示或滚动。后台启动或切页时不会把入场动画暂停在透明状态。

内置独立 CPython 3.12.15、musicdl 2.14.1 和固定版本依赖，无需手动配置 Python 或 venv。支持歌曲/歌手搜索、公开歌单导入、试听、单首或批量下载、音源附带歌词保存、音频解码校验和兼容格式播放缓存。平台注册数量不代表全部接口当前可用，受保护音源继续不导入。

完整音乐版需要 macOS 14+，分别提供 Apple 芯片 arm64 和 Intel amd64 DMG。运行时随 .app 移动，保留各依赖原许可证并对原生扩展、动态库和子程序签名。更新保留原有设置、任务和下载文件。musicdl 独立采用 PolyForm Noncommercial 1.0.0，包含该引擎的音乐构建适用于个人非商业使用。

当前为 ad hoc 本地签名，未做 Apple Developer ID 签名或 Apple 公证。安装包 SHA-256 见同名校验文件；首次打开方法见 DMG 内说明。真实 Mac 微信视频号捕获仍取决于客户端行为及本机授权。
