拾流 1.8.0 完善 iPhone 轻量连接版，并修正更新状态的表达。

- iPhone 通过同一 Wi-Fi 连接 Mac，可从 Safari 添加到主屏幕。发送分享链接、选择画质、批量加入下载队列，完成后预览或保存到手机。下载与媒体处理仍由 Mac 执行，手机无需安装额外运行时。
- 全局搜索和筛选在 Mac 执行，资源与任务每页最多 30 项；翻页替换旧列表、画质缓存随页释放。下载中约 1.5 秒刷新、空闲约 10 秒，退到后台停止轮询并中止读请求。媒体按需读取，文件直接交给浏览器下载，避免把完整视频加载为页面 Blob。
- 手机可暂停 / 继续电脑的后续下载队列；正在进行的传输保留。电脑设置的预约与优先级同步显示。
- 构建自动检查手机资源体积：HTML / JS / CSS 总计不超过 160 KiB，含主屏幕图标的页面资源不超过 256 KiB。本版约 134 KB / 143 KB，无新增运行依赖。这些是页面文件体积，不代表 iPhone 运行内存或用户媒体文件大小。
- 更新提示区分「当前已是最新版本（版本号）」与「新版安装包尚未就绪」，检查失败明确给出网络原因；设置中的版本标题也与实际状态一致。
- 保留上一版共用 Node.js、运行时裁剪、任务预约和限速，以及 macOS 原生标题栏拖动。成功升级后只保留最新版应用，并清理旧应用与暂存安装包。

macOS 14+；Apple 芯片与 Intel 安装包分别发布。手机连接默认关闭，需在设置开启；Mac 必须保持唤醒。手机页面是连接版，不支持脱离 Mac 独立下载。当前安装包为 ad-hoc 签名，尚未使用 Developer ID 或 Apple 公证。手机端已经过窄屏浏览器和真实本地 API 验证，尚未完成这版的 iPhone 真机验收。
