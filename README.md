## macOS 版本

**Mac 安装包：[Apple 芯片 arm64](https://github.com/meteor060606111-pixel/ResourceLens/releases/download/v1.4.0-macos/ResourceLens-1.4.0-macos-arm64.dmg) · [Intel amd64](https://github.com/meteor060606111-pixel/ResourceLens/releases/download/v1.4.0-macos/ResourceLens-1.4.0-macos-amd64.dmg)**。发布状态及校验文件见 [macOS Release](https://github.com/meteor060606111-pixel/ResourceLens/releases/tag/v1.4.0-macos)，自动构建状态见 [Actions](https://github.com/meteor060606111-pixel/ResourceLens/actions/workflows/macos.yml)。

需要 macOS 13.5 或更高版本。打开 DMG，将 ResourceLens.app 拖入 Applications；下载、画质选择、暂停续传和媒体预览沿用原工作台，媒体引擎内置。macOS 系统代理、钥匙串证书、Finder 定位、单实例和子进程管理已分别适配。

默认下载目录为 `~/Downloads/ResourceLens`，配置、日志、证书与任务保存在 `~/Library/Application Support/ResourceLens/data`。首次捕获需要 macOS 网络设置及钥匙串授权；停止捕获或正常退出恢复原代理。更新使用 DMG 拖拽替换应用，保留本机数据。

当前构建使用 ad hoc 本地签名，尚未做 Apple Developer ID 公证。首次启动方法、源码构建、权限与验证边界见 [macOS 说明](installer/macos/README.md)。真实 Mac 微信捕获仍需本机验证；下方旧版微信实测记录均为 Windows 结果。

```bash
# macOS：需要 Go、Node.js/npm、Python 3 和 Xcode Command Line Tools
./build-macos.sh
```

- 新增快手、小红书公开页面适配。作品需要正常向当前请求提供媒体数据；登录、验证、删除及不可访问作品会显示具体原因。不能保证所有分享链接可用，可在正常浏览播放后捕获实际媒体流。

## 从源码构建

需要 Windows 10/11 x64、Go 1.24 以上、Node.js 22.19 以上，以及 FFmpeg、FFprobe、yt-dlp。仓库不包含运行数据、证书、下载视频或大型引擎二进制。按 [引擎来源](video-engine/ORIGIN.md) 将三个媒体工具放在 video-engine；Node.js 可放在系统 PATH 或 video-engine。

```powershell
.\build.ps1
# 或指定本机的工具路径和输出位置
.\build.ps1 -GoExecutable 'D:\tools\go\bin\go.exe' -NodeExecutable 'D:\tools\node\node.exe' -OutputFile '.\ResourceLens.exe'
```

脚本安装锁定的前端依赖、运行后端检查、生成 Windows 资源并编译应用。go-winres 缺失时安装固定版本 v0.3.3。应用运行需要 WebView2；正常使用编译好的应用不需要安装 Go。

本地检查使用合成短视频和隔离下载目录，不依赖私人账户。可选的真实旧安装包测试通过 RESOURCELENS_PREVIOUS_INSTALLER 指向 1.1.8 安装包；快手、小红书当前公网样例受验证或作品不可用限制，验证的是正确报错，未宣称两个平台真实下载实测成功。

在线更新清单格式如下，安装包大小上限 1 GB，版本和 SHA-256 都会再次核对：

```json
{"version":"1.3.0","url":"https://your-host/ResourceLens-1.3.0-setup.exe","sha256":"安装包的64位SHA256"}
```

Windows 资源捕获与下载工具，安装在 D:\ResourceLens。双击 ResourceLens.exe 或 启动拾流.cmd 启动。需要 Windows 10/11 x64 和 WebView2；请保留 EXE 旁的 video-engine 文件夹，编译好的程序无需另装 Node.js 或 Go。

## 抖音下载

点击“添加链接”，粘贴“复制链接”得到的完整分享文本、短链或单个作品地址。程序自动提取链接并解析标题，添加成功后点击“下载”，在下载任务中查看进度。公开 HTTP 解析未取得播放数据时，会自动调用本机 Edge / Chrome 获取同一作品的数据。

解析浏览器使用独立临时目录，不读取用户浏览器资料。平台要求登录或验证、作品不可访问、图文、主页和直播等情况会反馈具体原因。每次下载尝试重新获取地址；同一媒体更换 CDN 或签名后可以续传，检测到内容改变时使用新的缓存。

## 微信视频号

1. 点击“开始捕获”，开启 HTTPS 捕获。
2. 保持拾流捕获开启，在电脑版微信中正常打开并播放视频。
3. 资源列表出现实际视频标题后，选择画质并下载。程序处理视频号文件并校验 MP4。

捕获页提供“检查微信连接”，自动显示是否收到视频号请求、是否取得媒体信息，以及微信是否仍连接原来的本地代理。若微信沿用旧代理，请保持捕获开启，正常退出并重新打开微信，再进入视频号播放。微信登录需要你自己完成。

视频号分享链接只加入待捕获列表；只取得加密媒体地址而缺少视频信息时，下载按钮也暂时禁用。实际播放信息补全后才开放下载，避免把网页、封面或加密数据误报为可播放视频。

解码种子按原软件使用的 ISAAC-64 规则生成 128 KB 前缀处理数据。必要的媒体种子保存在本机任务记录中；微信账号 Cookie 和 Authorization 不写入记录，也不复制给媒体下载域名。

## 通用捕获与下载

开始捕获后，Windows 系统代理临时指向本机 127.0.0.1:18999；HTTPS 捕获使用本机生成的当前用户证书。在浏览器中打开页面、播放媒体，资源会加入列表。支持搜索、类型和域名筛选、复制链接、批量下载，以及直接添加 B 站播放页、M3U8 / MPD 清单或文件直链。

下载支持并发队列、分段传输、重试和进度显示。视频任务显示解析、下载、合并及校验阶段；MP4 经过容器、视频流与时长校验后才显示完成。HTML 错误页不会显示为下载成功。

失败任务可以点击重试；适用的视频任务保留临时数据用于续传。主动取消或退出时管理下载器及合并子进程，避免后台孤立任务。保存目录、分段数和并发数可在设置中调整。

“打开文件夹”打开当前保存目录；已完成任务旁的文件夹按钮打开实际文件所在目录并选中该文件。

停止捕获或正常退出时恢复原系统代理。异常退出后，重新启动会检查恢复记录；若用户已改用其他代理，程序保留用户的新设置。证书可以在设置中移除。

## 当前验证范围

- 视频号独立 Go 解码与原发布软件嵌入 WASM 的三个完整输出 SHA-256 一致。
- 本地检查通过“代理捕获元数据 → 加密媒体下载 → 前缀处理 → FFprobe 校验 → 提交 MP4”，输出与原明文逐字节一致。
- IPv4 / IPv6 的微信连接检查使用 Windows 原生 TCP 表，已通过真实本机连接检查。
- 抖音生产浏览器脚本取得同一公开作品的播放数据；实际媒体前 4 KB 返回 HTTP 206、video/mp4 和 MP4 文件头。没有下载整段网站测试视频。
- 已在正常登录的电脑版微信中完成实际捕获：页面及脚本改写生效，列表取得 32 条有标题和解码信息的视频资源。真实媒体前 4 KB 经处理还原为 MP4 ftyp / isom，没有下载整段网站测试视频。

源码使用 Go、Wails 和 Vue，媒体解析与合并使用 video-engine 中的工具。诊断日志为 data\app.log，资源及任务记录为 data\session.json。本工具为独立实现，不是原软件的修改版本。

## 1.1.6 缓存与重复资源处理

视频号页面和 JS 的依赖脚本逐层刷新缓存，捕获期间移除相关条件缓存头。补齐详情回调中的嵌套对象表达式处理，令牌补充可更新同一媒体记录；播放器的重复范围请求合并为同一视频。

## 1.1.7 画质与实际大小

视频号的媒体信息大小与默认播放地址可能属于不同版本。现在将平台标注大小单独保留；下载前探测各可用档位的实际大小和 MP4 分辨率，任务中显示实际所选版本。默认选择最高可获取，匹配不到标注大小时明确注明。可手动选择“匹配平台标注大小（失败则停止）”，此模式未取得对应大小版本就报错，或选择当前播放版本。

当前客户端中，原软件使用的仅保留 encfilekey 和 token 的超清地址已实测返回 HTTP 400；不能保证取得上传时的原文件。大小相同只是与平台标注匹配，不等于逐字节验证上传原文件。视频号处理仅恢复平台媒体前缀，不重新编码或压缩音视频。

抖音使用候选地址各自的分辨率、帧率和编码信息，优先选择更高清晰度，再比较帧率及同编码码率。较高档地址不可用、只有无音轨 DASH 时会说明；不把纯视频流误报为带声音的完整 MP4。下载任务与资源详情显示实际版本及 HTTP 确认的大小。通用视频解析也优先选择最高画质音视频流，合并或封装成 MP4，不重新编码。

已下载的文件保留；旧文件需要重新下载才会取得新选择的版本。

## 1.1.8 捕获重连

视频号媒体回传使用本机独立、跨程序重启保留的窄权限地址；每次开始捕获有独立的状态标记。页面保留最近 24 条媒体信息，当拾流或捕获重新启动时，取得本机响应确认后自动补发；单独清空资源列表不会批量恢复旧资源。页面的回传不包含微信账户 Cookie 和 Authorization，回传能力不提供应用 API 访问。

首次从旧版本更新仍需保持捕获开启，完全退出并重新打开一次微信，再进入视频号。此后新页面能够自动重连。连接提示会单独区分“微信旧页面未加载捕获脚本”和正常等待媒体信息。画质选项保存在本机界面中，重开拾流可继续使用上次选择。
